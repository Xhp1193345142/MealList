# 环境与启动指南

## 端口分配

端口已在初始化时与本机监听端口核对，避开了 3000、3001、5000、5173、5432、7000、8000、8080、9000 等现有占用。

| 环境 | API | PostgreSQL | 小程序开发服务 |
| --- | ---: | ---: | ---: |
| dev | 28681 | 25432 | 28680 |
| preview | 28682 | 25433 | 28680 |
| production-local | 28683 | 25434 | 不单独运行 |

小程序最终在微信开发者工具中导入 `apps/miniprogram/dist` 预览；`28680` 是 Taro 本地编译服务端口，不作为对外 API。

## 首次启动

1. 复制对应环境示例文件，例如 `cp .env.development.example .env.development`；
2. 安装依赖：`pnpm install`；
3. 启动开发数据库：`pnpm db:dev:up`；
4. 生成 Prisma Client：`pnpm --filter @meallist/api prisma:generate`；
5. 创建开发迁移：`pnpm --filter @meallist/api prisma:migrate:dev`；
6. 启动 API：`pnpm dev:api`；访问 `http://localhost:28681/api/v1/health`；
7. 启动小程序编译：`pnpm dev:mini`，再用微信开发者工具导入 `apps/miniprogram/dist`。

## 预览与本地生产

切换环境时只使用对应的 `.env.*` 文件与数据库端口。preview 验收通过后，按照《开发流程与架构规范》的阶段 D 执行备份、迁移和 production-local 冒烟验证。
